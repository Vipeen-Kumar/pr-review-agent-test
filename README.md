# PR Review Agent – Test Repository

⚠️ **IMPORTANT: This repository is created exclusively for testing purposes of the PR Review Agent project.**

This is a simple JavaScript calculator repository used to test and validate the functionality of an AI-powered GitHub Pull Request Review Agent.

## Purpose

The repository is intended to test:

- GitHub Issue creation and tracking.
- Pull Request creation and issue linking.
- Automatic fetching of PR details and code diffs.
- AI-powered code review using Google Gemini.
- Review comments posted directly to GitHub.
- User attribution (reviewer's name and email) in GitHub comments.
